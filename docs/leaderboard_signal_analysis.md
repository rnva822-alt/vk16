# Сигнал лидерборда после временного ансамбля

Текущий подтверждённый лидер — `submission_advanced_2.csv` с F1 **0,47355959**. Это на 0,00580512 выше более консервативного `submission_advanced_1.csv` и на 0,00689292 выше предыдущего лидера с весами CatBoost/LightGBM 0,65/0,35. Таким образом, скрытый тест предпочитает ансамбль, где заметную роль получают временно-взвешенный CatBoost и LightGBM с историческими target encoding.

Следующий offline-поиск должен сохранять структуру лучшего ансамбля и варьировать только устойчивые направления: силу временного затухания, регуляризацию и сглаживание исторических ID-признаков, а также усреднение нескольких CatBoost seed. Непереносимые групповые пороги следует исключить: проверка переноса между двумя последними временными фолдами ухудшила F1 по сравнению с единым порогом.

> Цель F1 = 0,55 остаётся ориентиром, а не прогнозом. Подтверждённый рост показывает направление, но достижение такого скачка потребует появления существенно более сильного сигнала, а не только локальной настройки порога.
