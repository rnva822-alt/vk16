# Проверенные гипотезы и причины их отклонения

## Краткий ответ

Была проверена не одна идея, а **23 крупные hypothesis families** и серия контролируемых экспериментов `EXP_EXEC001–EXP_EXEC014`, затем ещё три независимых направления: adversarial de-drifting, past-only graph embeddings и FT-Transformer. Единственным кандидатом, который остался одобренным, является исходный **frozen champion**: recency CatBoost + два LightGBM с весами `0.70 / 0.20 / 0.10` и фиксированным threshold `0.504`. Его подтверждённый public F1 равен **0.4792176039**. [1]

Ни один новый кандидат не прошёл единый acceptance gate: на **обоих** защищённых temporal folds он должен был повысить F1 минимум на `+0.0025` и не ухудшить AUC относительно того же заново обученного champion. Поэтому «был полезен на более раннем fold» не считалось достаточным основанием для promotion. [1]

## 2. Все проверенные hypothesis families

Следующая таблица является полной картой **информационных гипотез**, а не просто списком файлов. Несколько близких скриптов объединены в одну строку, если они проверяли один и тот же источник сигнала. Это важно: изменение seed, веса, порога или варианта уже отвергнутого механизма не создаёт новой независимой гипотезы.

|---:|---|---|---|---|
| 1 | CatBoost core variants | Иная глубина, regularization, CTR, grow policy или boosting улучшит temporal transfer | Depth/LR/regularization, grow policy, CTR/composite CTR, `has_time`, quantization, seeds | Повторяемого temporal gain нет; например `has_time` дал latest `ΔF1 = −0.016146`. [1] |
| 2 | LightGBM core variants | Структура дерева и regularization уменьшат FP | Leaves, bagging, DART/GOSS/RF, subsampling, linear trees, seeds | Frozen neutral/diverse LGB оказались наиболее стабильной парой; linear trees дали latest `ΔF1 = −0.005016`. [1] |

## 3. Контролируемая execution series `EXP_EXEC001–014`

Это отдельные воспроизводимые run directories, созданные после широкого family audit. Здесь видно, почему даже самые «близкие» идеи не получили promotion.

| Experiment | Конкретное изменение | Penultimate ΔF1 | Latest ΔF1 | Latest ΔAUC | Почему отклонён |
|---|---|---:|---:|---:|---|
| `EXP_EXEC001` | Независимое воспроизведение champion | `0.000000` | `0.000000` | `0.000000` | Approved baseline reproduction, а не challenger. |
| `EXP_EXEC002` | Activity + bot geometry + profile/country compact union | `−0.004754` | `−0.014325` | `−0.002385` | Removed 33 TP, но только 24 FP: gain отсутствует. |
| `EXP_EXEC003` | Строгая LGB leaf/split regularization | `+0.006500` | `−0.004206` | `−0.000372` | Старый fold улучшился, latest не перенёс эффект. |
| `EXP_EXEC004` | Nested OOF 3-probability stacker | `−0.015484` | `−0.019326` | `+0.000019` | Recall/demotion loss. |
| `EXP_EXEC005` | Disagreement features + global CatBoost correction | `+0.003447` | `−0.007734` | `+0.000093` | Predicted positives выросли; FP росли быстрее TP. |
| `EXP_EXEC006` | Soft-LGB + disagreement correction | `+0.005943` | `−0.004817` | `+0.000163` | Recall выше, но precision хуже. |
| `EXP_EXEC007` | Bot/behaviour compact interactions + stability filter | `−0.005387` | `−0.010328` | `−0.001480` | Упали и precision, и recall. |
| `EXP_EXEC008` | Natural-prior clipped-logit stacker | `−0.283895` | `−0.284425` | `+0.001953` | Probability-scale collapse при frozen threshold. |
| `EXP_EXEC009` | Ещё более сильная LGB regularization | `+0.003568` | `−0.007182` | `−0.000843` | Precision снизилась при почти flat recall. |
| `EXP_EXEC010` | Stacker + HistGradientBoosting probability | `−0.015338` | `−0.018764` | `+0.000028` | Demoted 90 TP, чтобы убрать 202 FP; F1 упал. |
| `EXP_EXEC011` | Relationship/chronology compact interactions | `+0.001023` | `−0.013924` | `−0.001408` | Inner-stable features не дали multivariate OOT gain. |
| `EXP_EXEC012` | Interactions + nested stacker | `−0.012640` | `−0.026328` | `−0.001389` | Ошибки interaction и stacker compounded. |
| `EXP_EXEC013` | Forward-only threshold selection | `+0.004105` | `−0.003983` | `0.000000` | Recall выросла, но precision упала; latest F1 не прошёл gate. |
| `EXP_EXEC014` | Fixed 5-component blend с small regularized LGB mass | `−0.014553` | `−0.019467` | `+0.000655` | Precision выше, но severe recall loss. |

**Общий результат серии.** Самыми близкими к требованию по F1 на одном старом fold были `EXP_EXEC003`, `EXP_EXEC005`, `EXP_EXEC006`, `EXP_EXEC009` и `EXP_EXEC013`, но каждый ухудшил latest protected fold. Это и есть причина, по которой они не были «дотюнены» дальше: такое действие превращает validation в selection leakage и не даёт законного основания рисковать последней submit attempt. [1]

## 4. Последние три независимые hypotheses

После `EXP_EXEC001–014` были проверены именно новые, не дублирующие foundation branches. Все они использовали те же champion weights и threshold `0.504`; test inference не проводился. [4]

| Experiment | Hypothesis | Penultimate ΔF1 / ΔAUC | Latest ΔF1 / ΔAUC | Причина отклонения |
|---|---|---:|---:|---|
| `EXP_ADV_DRIFT_001` | Nested early-vs-late adversarial classifier может указать features, которые надо удалить из-за temporal shift | `−0.007926 / −0.004258` | `−0.024621 / −0.005410` | Domain AUC был высоким (`0.802797` / `0.864784`), но drift features были одновременно target-predictive; удаление повредило ranking и F1. |
| `EXP_GRAPH_001` | Past-only owner–content graph embeddings добавят relational signal | `−0.004870 / −0.000254` | `−0.014159 / −0.000121` | Coverage недостаточен: latest owner seen `49.82%`, content seen `15.99%`, both seen `3.05%`; graph слишком разрежен. |
| `EXP_FT_001` | FT-Transformer создаст architecture diversity beyond trees | `−0.205004 / −0.056008` | `−0.096820 / −0.049221` | Standalone model слабее champion и по ranking, и по F1; blend stage не разрешён. |

Три связанные исходные идеи были закрыты **без повтора модели**, потому что они не являются independent information source: prior-probability shift — это calibration/prevalence post-processing; boundary gated stacker — это local router/stacker; TP-only anomaly detector — anomaly score плюс forced boundary demotion. Все три относятся к уже gate-failed families. [4]

## 5. Почему большинство идей не переносились на latest fold

Основной предел не был одной «поломанной» feature или одной неправильной настройкой. На latest fold большая часть ошибок концентрировалась в уже predicted-positive boundary `[0.510, 0.650)`: там 1,172 rows, из которых 799 FP и 373 TP. В этом пространстве TP и FP существенно перекрываются по bot context, activity, content age и profile attributes. Поэтому два типичных типа correction дают противоположные, но оба плохие результаты: demotion уменьшает FP ценой многих TP, а попытка вернуть TP одновременно поднимает новые FP. [5]

Кроме того, в данных есть сильный temporal/platform shift. Однако experiments показали, что удалять drift-sensitive features нельзя автоматически: они могут быть сдвинуты по распределению и всё равно оставаться важными predictors целевой переменной. То же объясняет, почему более строгая regularization, graph fallback для unseen nodes и независимый neural architecture не дали требуется repeated gain. [4]

## 6. Что означает окончательный статус

| Статус | Смысл |
|---|---|
| **Approved champion** | Единственный artefact, который воспроизводимо даёт лучший public result и соответствует всем schema/hash checks. |
| **Rejected by temporal gate** | Реально обученный кандидат не выполнил F1/AUC contract на penultimate и latest folds. |
| **Closed as duplicate** | Новый run не запускался, потому что он лишь менял упаковку уже провалившейся family, а не information set. |
| **Diagnostic only** | Наблюдение объясняет ошибки, но не создаёт leakage-safe predictive correction. |
| **Blocked by missing data** | Нового organizer-sanctioned raw source, который мог бы открыть независимую hypothesis, нет. |

Следовательно, последний submission attempt сохраняется для frozen champion, а не для очередного варианта порога, seed, stacker, router, anomaly score или interaction. Законно открыть следующую экспериментальную ветку может только новый, публично доступный всем участникам organizer-sanctioned raw signal либо явное разрешение, меняющее допустимый information set.
