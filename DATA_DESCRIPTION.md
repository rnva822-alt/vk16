# Описание колонок

| Колонка | Описание |
|---|---|
| `claim_id` | Идентификатор жалобы. В `submission.csv` используется как идентификатор строки |
| `first_event_time` | Время первого события по жалобе |
| `registered_year` | Год регистрации пользователя, отправившего жалобу |
| `age_bucket` | Возрастная группа пользователя, отправившего жалобу |
| `friends_bucket` | Группа по количеству друзей у пользователя, отправившего жалобу |
| `sex` | Пол пользователя, отправившего жалобу |
| `has_avatar` | Признак наличия аватара у пользователя, отправившего жалобу |
| `has_school` | Признак того, что у пользователя, отправившего жалобу, указана школа |
| `has_university` | Признак того, что у пользователя, отправившего жалобу, указан университет |
| `is_private_profile` | Признак приватного профиля у пользователя, отправившего жалобу |
| `platform` | Закодированная платформа, с которой была отправлена жалоба |
| `os` | Операционная система устройства пользователя, отправившего жалобу |
| `registered_phone_country_id` | Закодированная страна по номеру телефона, использованному при регистрации отправителя жалобы |
| `mobile_phone_country_id` | Закодированная страна по мобильному телефону отправителя жалобы |
| `profile_country_id` | Закодированная страна, указанная в профиле отправителя жалобы |
| `ip_country_id` | Закодированная страна по IP-адресу отправителя жалобы |
| `claim_user_registered_year` | Год регистрации пользователя, на которого пожаловались |
| `claim_user_age_bucket` | Возрастная группа пользователя, на которого пожаловались |
| `claim_user_friends_bucket` | Группа по количеству друзей у пользователя, на которого пожаловались |
| `claim_user_sex` | Пол пользователя, на которого пожаловались |
| `has_claim_user_avatar` | Признак наличия аватара у пользователя, на которого пожаловались |
| `has_claim_user_school` | Признак того, что у пользователя, на которого пожаловались, указана школа |
| `has_claim_user_university` | Признак того, что у пользователя, на которого пожаловались, указан университет |
| `is_claim_user_private_profile` | Признак приватного профиля у пользователя, на которого пожаловались |
| `claim_user_registered_phone_country_id` | Закодированная страна по номеру телефона регистрации пользователя, на которого пожаловались |
| `claim_user_profile_country_id` | Закодированная страна, указанная в профиле пользователя, на которого пожаловались |
| `claim_user_bot_prediction_score` | Скор вероятности того, что пользователь, на которого пожаловались, похож на бота |
| `user_bot_prediction_score` | Скор вероятности того, что отправитель жалобы похож на бота |
| `are_friends` | Признак того, что отправитель жалобы и пользователь, на которого пожаловались, состоят в друзьях |
| `claim_type` | Закодированный тип объекта или контента, на который отправлена жалоба |
| `content_registered_time` | Время создания контента, на который отправлена жалоба |
| `id_content_owner` | Идентификатор владельца контента |
| `id_content` | Идентификатор контента без служебного префикса |
| `claim_reason_start` | Причина жалобы, выбранная пользователем при отправке |
| `additional_likes_count` | Количество лайков за последнюю неделю, связанных с объектом или пользователем в контексте жалобы |
| `additional_friend_request_count` | Количество заявок в друзья за последнюю неделю |
| `additional_friend_accept_count` | Количество принятых заявок в друзья за последнюю неделю |
| `is_valid` | Целевая переменная в `train.csv`: `1` - жалоба признана валидной, `0` - жалоба отклонена |
